# Pawstore (Pet E-commerce)

A user-friendly e-commerce platform dedicated to pet products and accessories.

### Key Features
* **Product Catalog:** Dynamic browsing with category filtering.
* **Shopping Cart:** Seamlessly add, remove, and update items for purchase.
* **Secure Checkout:** Streamlined flow for a better shopping experience.

### Tech Stack
* React, Node.js, Express, MongoDB
* CSS Modules / Tailwind CSS
